Add the icons to your Mermaid diagrams

  1. Copy iconify/databricks-color.json into your project. Serve it as a static file.
  2. Register the pack before you render a diagram.
  3. Write each icon id as databricks-color:<slug>. CATALOG.md lists every slug.
import mermaid from 'mermaid';

mermaid.registerIconPacks([
  {
    name: 'databricks-color',
    loader: () => fetch('/icons/databricks-color.json').then((r) => r.json()),
  },
]);

mermaid.initialize({ startOnLoad: true });
architecture-beta
    service wh(databricks-color:sql-warehouse)[SQL Warehouse]
    service gold(databricks-color:lakehouse-storage)[Managed Tables]
    gold:R --> L:wh

The pack databricks-color keeps the Databricks Lava artwork. The pack databricks holds the same icons in one color. That pack inherits currentColor, so Mermaid gives the icons the text color of the diagram. Use it for a dark theme.

A browser blocks fetch() on file://. If your page must run from disk, load iconify/databricks.js with a classic script tag instead. It sets window.databricksColorIconPack and window.databricksIconPack. This page uses that method.

The icon pack did not load. Mermaid draws a “?” for each icon. Make sure that the iconify/ directory is one level above this page. As an alternative, serve the folder with npx serve ..

A full platform architecture

This diagram uses subgraphs for the boxes, style for the fill and the border of each box, stroke-dasharray for a dashed border, and a class for the navy bars. Every arrow joins a box border, not an icon, because the edge points at the subgraph and not at a node inside it. Dagre chooses the arrangement, so the boxes do not sit exactly where a hand-drawn diagram puts them. Boxes with no Databricks product, such as the data sources, are plain labels.

Flowchart with icon nodes

The architecture-beta type has no edge labels and little layout control. A flowchart uses the same icon pack through the @{ icon: … } node shape. This shape needs Mermaid 11.3 or later. A flowchart gives you edge labels, subgraphs and every layout direction. 

flowchart LR
    src@{ icon: "databricks-color:lakeflow-connect", form: "square", label: "Lakeflow Connect", pos: "b" }
    dlt@{ icon: "databricks-color:spark-declarative-pipelines", form: "square", label: "Declarative Pipelines", pos: "b" }
    tbl@{ icon: "databricks-color:lakehouse-storage", form: "square", label: "Managed Tables", pos: "b" }
    uc@{ icon: "databricks-color:unity-catalog", form: "square", label: "Unity Catalog", pos: "b" }
    bi@{ icon: "databricks-color:ai-bi-dashboards", form: "square", label: "AI/BI Dashboards", pos: "b" }

    src -->|"CDC, hourly"| dlt
    dlt -->|"expectations"| tbl
    tbl --> bi
    uc -. "lineage + ABAC" .-> tbl

All icons from the databricks-color pack, drawn by Mermaid. Each one must show the Databricks Lava artwork. A gray box or a “?” means that the pack did not load. The build generates this section from the catalog, so it always covers every icon.
